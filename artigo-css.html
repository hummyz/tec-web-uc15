CSS – Estilo e Aparência

Última versão: CSS é mantido como um padrão vivo (Living Standard), recebendo constantes atualizações por módulos. O CSS (Cascading Style Sheets) é utilizado para controlar a aparência visual das páginas web.

Principal funcionalidade

Personalizar o design do site através de:

  • Cores
  • Responsividade
  • Layouts
  • Animações
  • Espaçamentos
  • Fontes

Exemplo de uso

Se o HTML é o esqueleto do site, o CSS é a aparência, tornando a página moderna, organizada e agradável para o usuário.
