HTML – Estrutura da Página

Última versão: HTML Living Standard (evolução contínua do HTML5).

Principal funcionalidade

O HTML (HyperText Markup Language) é a linguagem responsável pela estrutura e organização do conteúdo de uma página web.

Definir elementos como:

  • Títulos
  • Parágrafos
  • Imagens
  • Links
  • Formulários
  • Tabelas

Exemplo de uso

O HTML funciona como o esqueleto de um site, criando toda a sua estrutura básica.
